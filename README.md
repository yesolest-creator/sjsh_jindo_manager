# 📚 수업 진도 관리 앱

교차시간표를 지원하는 수업 진도 관리 Streamlit 앱입니다.

---

## 🚀 실행 방법

### 1단계: 파이썬 패키지 설치
터미널(명령 프롬프트)에서 아래 명령어 실행:
```
pip install -r requirements.txt
```

### 2단계: 앱 실행
```
streamlit run app.py
```
브라우저가 자동으로 열리고 앱이 실행됩니다.

---

## 📋 주요 기능

### ⚙️ 시간표 설정
- 반별로 고정 / 원시간표 / 교차시간표 유형 설정
- 요일×교시 직접 입력 또는 CSV 파일 업로드
- CSV 형식: `반,요일,교시` (예: `1반,월,2`)

### 📅 원/교차 설정
- 날짜 범위 일괄 설정 (예: 5/1~5/6 → 원시간표)
- 날짜별 개별 설정 가능 (일 단위)

### 📖 단원 관리
- 차시번호 + 단원명 입력
- 표에서 직접 수정/삭제 가능

### 📊 진도표
- 날짜별 × 반별 진도 현황 (엑셀 형태)
- 오늘 날짜 자동 강조 표시 (🔵)
- 원/교차 시간표 뱃지 표시
- 주차별 수업 요약 표
- 차시별 반별 수업 날짜 현황
- 인쇄용 보기
